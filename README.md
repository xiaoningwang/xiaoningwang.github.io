## Visitor statistics

The shared footer uses a dedicated Flag Counter (`wNrs` on `s01`) to show
pageviews and visitor counts by IP-derived country/territory. It loads only in
Jekyll's `production` environment so local previews do not affect the counts.
GitHub Pages uses this environment; for a manual release build use
`JEKYLL_ENV=production bundle exec jekyll build`.

Settings are in `_config.yml` under `visitor_stats`. Set `enabled: false` to
remove the widget. Keep the same counter ID to preserve its history. Details:
https://info.flagcounter.com/wNrs

Pageviews count image loads across all pages using the shared footer. Country
counts use the provider's default 24-hour visitor deduplication; they are not
all-time unique IP counts. Statistics start when installed and cannot recover
earlier traffic. Local verification and creation may contribute initial views.
The image updates approximately every five minutes. Blocked images, browser
caching, network failures and VPNs can affect counts/location accuracy. The
service receives the visitor's IP when loading the image; full IP addresses are
not displayed on this site. No account or email was registered for this widget.
According to the provider, free counters with no new visitors for over 30 days
may be removed. See https://flagcounter.com/faq.html for current service rules.
